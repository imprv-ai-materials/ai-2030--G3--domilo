# Domilo S.A. - strona firmy

Katalog wiedzy o firmie Domilo S.A.: ludzie, systemy i dane, historia. Jedna strona bez budowania i bez serwera (`index.html` + `img/`).

**Publikacja w GitHub Pages:** workflow `.github/workflows/pages.yml` publikuje ten folder przy każdym pushu do `main` (raz w repozytorium: *Settings → Pages → Source: GitHub Actions*).

Postać fikcyjna: Wszystkie firmy, osoby, systemy i adresy są fikcyjne; prawdziwe są tylko narzędzia, biblioteki i miasta.

Wygenerowano z `world/` narzędziem `tracks/_tools/world/world_website.py` - nie edytuj ręcznie.
